part 1.1 · convolutions from scratch

1. Four loops: I used two loops to visit every output pixel and two additional loops to visit every entry of the flipped kernel.

2. Two loops: I kept the two loops over the output pixels, but replaced the inner kernel loops with a NumPy window multiplication and sum.

3. SciPy and boundaries: My implementations use explicit zero padding and preserve the input dimensions.

(I ∗ K)[i, j] = Σu Σv Ipad[i + u, j + v] Kflip[u, v]

four_loops 
def convolve_four_loops(image, kernel):
    kh, kw = kernel.shape
    h, w = image.shape
    output = np.zeros((h, w), dtype=float)
    kernel = np.flip(kernel)
    pad_h, pad_w = kh // 2, kw // 2
    padded = np.zeros((h + 2*pad_h, w + 2*pad_w))
    padded[pad_h:pad_h+h, pad_w:pad_w+w] = image

    for i in range(h):
        for j in range(w):
            for p in range(kh):
                for q in range(kw):
                    output[i, j] += padded[i+p, j+q] * kernel[p, q]
    return output
two_loops 
def convolve_two_loops(image, kernel):
    kh, kw = kernel.shape
    h, w = image.shape
    output = np.zeros((h, w), dtype=float)
    kernel = np.flip(kernel)
    pad_h, pad_w = kh // 2, kw // 2
    padded = np.zeros((h + 2*pad_h, w + 2*pad_w))
    padded[pad_h:pad_h+h, pad_w:pad_w+w] = image

    for i in range(h):
        for j in range(w):
            window = padded[i:i+kh, j:j+kw]
            output[i, j] = np.sum(window * kernel)
    return output

I convolved the cameraman image with Dx = [1, 0, −1] and its vertical transpose Dy, then computed the gradient magnitude as sqrt(dx² + dy²). I binarized the magnitude image using a threshold of 0.27.

A lower threshold preserved more weak edges, but also introduced responses from the grass and image texture; a higher threshold removed that noise, but began to erase real contours.

part 2.1 · image sharpening

The Gaussian blur isolates low frequencies. Subtracting it from the original gives the high-frequency detail, which is added back with the unsharp-mask filter. These examples use a 9×9 Gaussian with σ=2 and α=1.

Isharp = I + α(I − G ∗ I) = (1 + α)I − α(G ∗ I)

Here, G ∗ I is the low-frequency blurred image, I − G ∗ I is the high-frequency detail, and α controls how much of that detail is added back.

part 2.3 · gaussian & laplacian stacks

I built six-level Gaussian and Laplacian stacks without downsampling. Each Gaussian level applies progressively stronger smoothing; subtracting adjacent Gaussian levels isolates a frequency band. Summing the Laplacian levels reconstructs the image.

part 2.4 · multiresolution blending

I build a Gaussian stack for the mask and Laplacian stacks for both inputs. At every level, the smoothed mask selects a contribution from each image; summing the blended frequency bands creates a seam that changes gradually across scales.

Lkblend = GkM ⊙ LkA + (1 − GkM) ⊙ LkB

Iblend = Σk Lkblend

Here, GM is the Gaussian stack of the mask, while LA and LB are the Laplacian stacks of the two source images.
